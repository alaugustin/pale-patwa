# Setting Up a Kwéyòl Learning Chat on an AI Platform

## Steps to Configure an AI Platform for Saint Lucian Kweyol

1. Open the app route `/ai-chat/configure` and copy the prompt from the page.
2. Log into your AI platform and start a new chat.
3. Paste the copied prompt as the first message so the assistant applies the tutor behavior.
4. Confirm the assistant response uses Saint Lucian Kweyol rules and dictionary-first behavior.

## Suggested Session Commands

- Translate words or phrases:
  `/translate [sample word or phrase]`
- Build a table of recent translations:
  `/translations-table`
- Estimate vocabulary count from chat history:
  `/vocabulary-count`

## Notes

- This workflow is platform-agnostic and no longer depends on ChatGPT-specific JSON chat settings.
- Keep the prompt source in one place by using the in-app configure page as the canonical version.
